# Vinyl Vibes - Sistem de Gestiune Viniluri

## Descriere Proiect
O aplicație C# destinată colecționarilor de viniluri. Aplicația permite organizarea colecției, monitorizarea stării discurilor și gestionarea împrumuturilor către prieteni.

## Funcționalități Principale
* **Gestiune Completă:** Adăugare, editare, ștergere și vizualizare pentru albume, artiști și persoane care împrumută.
* **Sistem de Grading:** Monitorizarea stării fizice a discului (Mint, Near Mint, etc.) cu avertismente la utilizare.
* **Control Împrumuturi:** Validarea numărului de discuri împrumutate; dacă se depășește o limită configurată, sistemul blochează noi acțiuni.

## Configurări
Aplicația va permite setarea unor parametri (limite împrumut, praguri de preț) dintr-o secțiune dedicată de configurări.
